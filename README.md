# yotogi — ネットロア 怪談コーパス & 民俗学解説データ

怪談生成アプリ「ネットロア」のデータ基盤。**3つのモチーフタグを選ぶ → AIが新作の怪談を書き下ろし、読後に民俗学的解説を添える**ための、コーパス・タグ体系・生成/解説の仕様一式。別のAI/開発者へ引き渡せるようまとめてある。

## このリポジトリに入っているもの

### データ（`data/`）
| ファイル | 中身 |
|---|---|
| `corpus.json` | **統合コーパス 2420話**（重複0・本文欠損0、最短385字）。`id/title/system/source/sourceUrl/bodyText/bodyChars`、青空文庫分は `author/ndc/shoshutsu` も持つ。生成の参照コーパス兼タグ抽出の母集団。 |
| `net.json` | ネット怪談（洒落怖）1770話の元シャードのうち初期450話分。`source=dangi`。 |
| `aozora.json` | 青空文庫パブリックドメイン怪奇譚 初期400話分。 |
| `tags_final.json` | **最終タグ体系（9軸386タグ）**。`axes[].tags[] = {tag, gloss, weight, tier}`。weight=コーパス出現話数の目安、tier=`core`(入口の主役)/`longtail`(絞り込み)。 |

> `data/raw/`（HTMLキャッシュ・元CSV 計約600MB）と設計アセット（mobile/mood/variants 等）は `.gitignore` で除外。スクリプトから再生成可能。

### タグ体系・コンセプト
- `CATEGORIES_v2.md` — **2420話から抽出した全386タグ**を軸ごと・core/longtail別の表で一覧（決定版）。
- `CATEGORIES.md` — 旧27タグ版（編集チームが入口を絞った初期案。経緯資料）。
- `CONCEPT.md` — プロダクトの核（巡る/読む体験の思想）。
- `IDEAS.md` / `IDEAS_MENU.md` / `DECISION.md` / `DESIGN_SPEC.md` — 検討経緯と画面方針。

### 民俗学解説（本リポジトリの主目的のひとつ）
- `FOLKLORE_COMMENTARY.md` — **「解説」機能の仕様**。怪談に対し依拠する民俗学的モチーフの型（見るなの禁忌／他界観／境界とケガレ／異類婚 等）を同定して鑑賞を深める補助テキストの、長さ・トーン・**捏造防止ルール**（AT/ATU話型番号は確信時のみ・学説は論者特定・ジャンル峻別・時代層を混在させない）・二段生成ゲート（Gemmaドラフト→Claude検証）まで規定。

### 生成
- `GENERATION_PROMPT.md` — 3タグ→怪談本文を書き下ろす生成プロンプト仕様。

### 収集スクリプト（`scripts/`）
- `net.mjs` — dangi.link（洒落怖まとめ）サイトマップから本文収集（Shift_JIS対応・オンディスクキャッシュ）。
- `aozora.mjs` — 青空文庫CSVからPD怪奇譚を収集（作家リスト＋キーワード）。
- `lib.mjs` — 共通ユーティリティ（CSV/フェッチ/HTML→テキスト）。

## コーパスの出典と素性
- **ネット怪談 1770話**: dangi.link「洒落怖超まとめ」より。サイトマップには記事URLが約14,971件あり、本データは新規1,320＋初期450を収集したもの（残り1万件以上の伸び代あり）。
- **古典怪談 650話**: 青空文庫（小泉八雲・岡本綺堂・泉鏡花・田中貢太郎・国枝史郎・橘外男ほか）。作品著作権フラグ「なし」=パブリックドメインのみ。

> ネット怪談は各投稿者由来のユーザー生成コンテンツ。研究・生成の参照用。再配布・商用利用時は各出典の権利状況を各自確認すること。

## 再生成
```bash
node scripts/net.mjs 450        # 洒落怖収集（要 data/raw キャッシュ or ネットワーク）
node scripts/aozora.mjs 400     # 青空文庫収集（要 data/raw/list_person_all_extended_utf8.csv）
```
